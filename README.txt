# Happy 2nd Anniversary Website 💜

## Open the website
Open `index.html` in a browser. Keep the `assets` folder beside it.

## Put it online for free with GitHub Pages
1. Create a new public GitHub repository.
2. Upload `index.html` and the entire `assets` folder (including `our-video.mp4`).
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub to publish the site and open the URL it gives you.

## WhatsApp reply
On the final page, your girlfriend enters the WhatsApp number that should receive her message, including country code, then writes her note and taps **Send to WhatsApp**. WhatsApp opens with the message prepared; she must press Send herself. For Sri Lanka, use `94` followed by the mobile number without its first `0`.

The video and photos are local assets, so upload the complete `assets` folder. Large video files may take a while to upload and may exceed GitHub's normal file-size limit; if so, host the video separately and replace the video source in `index.html` with its public video URL.
